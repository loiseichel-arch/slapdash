INSTALLER SLAPDASH SUR TON MAC
==============================

1. Dézippe le fichier téléchargé, puis dézippe chaque plugin.

2. Copie les plugins :
   - Slapdash.vst3       ->  ~/Library/Audio/Plug-Ins/VST3/
   - Slapdash.component  ->  ~/Library/Audio/Plug-Ins/Components/
   - Slapdash.app        ->  où tu veux (Applications par exemple)

   (Dans le Finder : menu Aller > Aller au dossier..., puis colle le chemin.)

3. Le plugin n'est pas signé par Apple : macOS le bloque au début.
   Ouvre le Terminal et colle ces commandes :

   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/Slapdash.vst3
   xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/Slapdash.component
   killall -9 AudioComponentRegistrar

   (Pour l'app : xattr -dr com.apple.quarantine /Applications/Slapdash.app)

4. Relance ton logiciel audio et fais un nouveau scan des plugins.
   Slapdash apparaît sous le constructeur « Planet Gloria ».


AAX (Pro Tools) : Slapdash.aaxplugin n'est pas signé PACE. Il ne se charge
que dans Pro Tools Developer, à copier dans :
   /Library/Application Support/Avid/Audio/Plug-Ins/
